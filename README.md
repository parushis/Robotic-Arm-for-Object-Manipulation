Purpose of This Project : A sandbox 

 - Learning robotic arm motion control

 - Testing servo configurations and movement sequences

 - Building reliable reset/home positions

 - Experimenting with object manipulation routines

Laying the groundwork for vision- or ML-driven control (e.g., object detection → grasping)


The mini arm reset and read mini ino files are relevant files taken from HiWonder S3 arm's repository as relevant to this project.
